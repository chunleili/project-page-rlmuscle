# RLMuscle project page

Project page for *RLMuscle: Muscle-Driven Character Animation via Reinforcement Learning*
(IEEE TVCG, under review).

Live at <https://chunleili.github.io/project-page-rlmuscle>.

Built from the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template),
same layout as the [MGPBD project page](https://chunleili.github.io/project-page-mgpbd).

## Layout

- `index.html` — the whole page
- `static/css`, `static/js` — Bulma + Font Awesome, vendored
- `static/images` — teaser, pipeline and result figures, downscaled to 1920 px wide
- `static/videos/RLMuscle-v2.mp4` — supplementary video (H.264 CRF 21, 1080p30, 26 MB)

The presentation deck is not stored here; the Slides button points at the
[`rlmuscle-assets` release](https://github.com/chunleili/chunleili.github.io/releases/tag/rlmuscle-assets)
on the personal-site repo.
